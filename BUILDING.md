# Muon Qt6 / KDE Frameworks 6

This fork includes a Qt6 port of the QApt 3.0.5 backend in `third_party/qapt`.
QApt is linked statically into Muon and its worker; the system Qt5 QApt library
is not used or replaced. DebconfKDE 1.2 must be built against Qt6.

## Ubuntu 26.04 build dependencies

```sh
sudo apt install build-essential cmake ninja-build extra-cmake-modules \
  dpkg-dev qt6-base-dev qt6-5compat-dev libkf6kio-dev libkf6dbusaddons-dev \
  libkf6i18n-dev libkf6iconthemes-dev libkf6xmlgui-dev libkf6colorscheme-dev libkf6widgetsaddons-dev \
  libdebconf-kde-dev libpolkit-qt6-1-dev libxapian-dev libapt-pkg-dev
```

## Build an installable package

```sh
./scripts/build-deb.sh
sudo apt install ./build-qt6/muon_5.8.0+qt6.1_amd64.deb
```

The package installs Muon in `/usr/bin`, desktop integration in `/usr/share`,
and its root worker in `/usr/lib/<architecture>/libexec/muon` (the KDE platform libexec directory).
The worker uses `org.kubuntu.qaptworker6`, with matching D-Bus activation and
Polkit policies, so it does not replace QApt's Qt5 worker.
Runtime library dependencies are generated by `dpkg-shlibdeps`; `apt install`
resolves them from the target distribution. Build the package on the Ubuntu
release and architecture where it will be installed.

Remove with `sudo apt remove muon`.

## Port status

The Qt6 port is experimental. Building from a fresh clone with the documented
dependencies, generating the `.deb`, and application startup have been checked
on Ubuntu 26.04 amd64. Initial user testing also confirms installation of the
Muon package, updates, and removal of two packages through Muon.
Installing packages through Muon, debconf prompts, and recovery from interrupted
transactions still need testing; authentication and package operations need
broader coverage. No package transactions are run by the build script.
The bundled QApt currently uses its English source strings.

The old distribution release upgrade integration still expects an external
releasechecker script that is not supplied by this repository.
